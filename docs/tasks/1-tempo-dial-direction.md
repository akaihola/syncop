# Tempo dial direction

## Problem

Dragging to the right increased the tempo, but the dial moved to the left.

## Requirements

- Make the dial move in the same direction as the drag.
- Use a standard or well-established Android widget so the control is easy to use.

This issue concerns the direction of movement. The separate BPM drag issue in
[TASKS.md](../../TASKS.md) concerns random small jumps in the value.
